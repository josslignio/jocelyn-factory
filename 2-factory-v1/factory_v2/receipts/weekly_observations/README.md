# weekly_observations — observations hebdomadaires (comptabilité runtime, hors git)

Les observations (`<sha>.json`) et le verrou `.index.lock` sont écrits par la factory à chaque refresh hebdomadaire
observé ; ce sont des données runtime, conservées sur disque et ignorées par git depuis FACTORY_REPO_HYGIENE_V1
(22/09/2026). Ce README est le seul fichier versionné du répertoire : il garde le chemin
`factory_v2/receipts/weekly_observations/` résoluble comme livrable de TR_WEEKLY_OPERATE_V1 (ROADMAP twitter-radar).
